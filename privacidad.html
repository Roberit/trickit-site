Política de privacidad

Última actualización: 18 de noviembre de 2026

1. Quiénes somos

Trickit es un proyecto de contenido educativo de Catastra Software Solutions (República Dominicana). Esta política explica cómo la herramienta interna Trickit Publisher y el sitio trickit.lat tratan la información. Contacto: contacto@trickit.lat.

2. Qué datos usamos

Trickit Publisher se conecta únicamente a las cuentas oficiales de Trickit en TikTok, YouTube, Instagram y Facebook, con autorización explícita del titular mediante OAuth. Accede solo a:

  • Información básica del perfil (nombre de usuario, nombre visible, foto de perfil) para mostrar en qué cuenta se publicará.
  • Tokens de acceso necesarios para subir y publicar videos creados por Trickit.
  • Datos de estado de cada publicación (por ejemplo, si se publicó correctamente).

No recopilamos datos de seguidores, no leemos mensajes privados y no accedemos a cuentas de terceros.

3. Para qué los usamos

Exclusivamente para subir y publicar contenido propio de Trickit, después de que una persona lo revisa y confirma. No vendemos, alquilamos ni compartimos datos con terceros, y no los usamos para publicidad.

4. Almacenamiento y seguridad

Los tokens se guardan cifrados en el servidor privado de Trickit y solo los usa el proceso de publicación. Los videos publicados quedan en las plataformas correspondientes bajo sus propias políticas.

5. Conservación y eliminación

Conservamos los tokens solo mientras la conexión esté activa. Puedes revocar el acceso en cualquier momento desde la configuración de seguridad de cada plataforma (por ejemplo, permisos de Google o la sección de apps conectadas de TikTok), o escribiendo a contacto@trickit.lat; eliminaremos los datos asociados en un máximo de 30 días.

6. Servicios de terceros

Trickit Publisher usa los Servicios de API de YouTube. Al usarlo aceptas los Términos de servicio de YouTube y se aplica la Política de privacidad de Google. El uso de información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado. También usamos la API de TikTok (sujeta a los Términos de TikTok) y la API de Meta para Instagram y Facebook.

7. Menores

Trickit Publisher no está dirigido a menores y no recopila datos de ellos.

8. Cambios

Publicaremos cualquier cambio en esta página con su fecha de actualización.

Privacy Policy (English)

Last updated: November 18, 2026

1. Who we are

Trickit is an educational content project by Catastra Software Solutions (Dominican Republic). This policy explains how the internal tool Trickit Publisher and the trickit.lat website handle information. Contact: contacto@trickit.lat.

2. Data we use

Trickit Publisher connects only to Trickit's official TikTok, YouTube, Instagram and Facebook accounts, with the owner's explicit OAuth authorization. It accesses only: basic profile info (username, display name, avatar) to show which account a post goes to; access tokens required to upload and publish Trickit-created videos; and post status data. We do not collect follower data, read private messages, or access third-party accounts.

3. How we use it

Solely to upload and publish Trickit's own content after a person reviews and confirms it. We do not sell, rent or share data with third parties, nor use it for advertising.

4. Storage and security

Tokens are stored encrypted on Trickit's private server and used only by the publishing process.

5. Retention and deletion

Tokens are kept only while the connection is active. You can revoke access at any time from each platform's security settings (e.g. Google permissions) or by emailing contacto@trickit.lat; associated data will be deleted within 30 days.

6. Third-party services

Trickit Publisher uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies. Trickit Publisher's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. We also use the TikTok API (subject to the TikTok Terms) and the Meta API for Instagram and Facebook.

7. Children

Trickit Publisher is not directed to children and does not collect their data.

8. Changes

Any changes will be posted on this page with the update date.
